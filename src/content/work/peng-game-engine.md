This is an older project of mine. It's a small, modern C++ game engine, made for the Programming 4 course. This was a learning project about game engine development and game programming patterns.

Patterns used:

- **Design patterns:** Command, Observer, Singleton, State
- **Sequencing patterns:** Game Loop, Update Method
- **Decoupling patterns:** Component, Event Queue, Service Locator
- **Optimization patterns:** Dirty Flag

After the engine library was done, I made Pac-Man. I built my own abstraction for XInput so it's playable with a controller. You can choose to play:

- Co-op
- Versus
- Singleplayer
