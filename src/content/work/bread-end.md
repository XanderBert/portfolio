I participated with some friends in the Global Game Jam 2024. The theme was "Make Me Laugh." So we started brainstorming and quickly decided that we wanted to do something with "dry humor." After looking up some videos, we found the one hilarious video of the falling bread slice.

https://www.youtube.com/watch?v=PvB0kWs2IPQ

We all thought it would be funny if the player could recreate endings for the falling bread slice, so we went to work and decided to use Unreal Engine.

After 48 hours of hard work, we succeeded at making this game:

![Bread End](/portfolio/media/work/bread-end/ejwvlo.jpg)

https://www.youtube.com/watch?v=3ILi8E_20W0

## What did I do?

I worked mainly on the logic for the endings and progression. Certain endings could unlock or change other items in the room to unlock more endings, so we needed a dynamic, easy-to-change, and robust system to unlock and change things in levels. I built this using Data Tables and Streaming Levels, so everyone on the team could easily specify which event unlocks or changes what. Once I finished that, I helped the other devs create the actual endings.
